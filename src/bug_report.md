# Дефект PRIME-001: число 1 ошибочно определяется как простое

- **Модуль:** `initial_with_bug/number_filter.py`.
- **Функция:** `is_prime`.
- **Первоначальный статус:** Open.
- **Серьёзность:** Major — ошибка влияет на основной алгоритм фильтрации простых чисел.
- **Ожидаемый результат:** `is_prime(1)` возвращает `False`; функция `filter_primes([1, 2, 3])` возвращает `[2, 3]`.
- **Фактический результат:** `is_prime(1)` возвращает `True`; число 1 попадает в список простых чисел.

## Воспроизведение

1. Загрузить исходную версию модуля `initial_with_bug/number_filter.py`.
2. Вызвать функцию `is_prime(1)`.
3. Получить результат `True` вместо ожидаемого `False`.
4. Дополнительно вызвать `filter_primes([1, 2, 3])` и получить `[1, 2, 3]` вместо `[2, 3]`.

**Обнаружившие тесты:** `test_is_prime_boundaries`, `test_filter_primes`.

## Исправление и повторная проверка

В исправленной версии условие `if number < 1:` заменено на `if number < 2:`. После исправления весь набор модульных тестов проходит успешно. Итоговый статус: **Closed**.
