# Практическая работа №2 — «Фильтр чисел»

Учебный проект по модульному и мутационному тестированию.

## Пять функций

| Функция | Назначение |
|---|---|
| `is_prime(number)` | Проверяет, является ли целое число простым. |
| `filter_primes(numbers)` | Возвращает простые числа из списка/кортежа. |
| `split_even_odd(numbers)` | Разделяет числа на чётные и нечётные. |
| `fibonacci_up_to(limit)` | Формирует последовательность Фибоначчи до заданного предела включительно. |
| `filter_divisible(numbers, divisor)` | Возвращает числа, делящиеся на заданный делитель без остатка. |

## Преднамеренная ошибка

В каталоге `initial_with_bug` находится исходная версия с дефектом: число `1` ошибочно считается простым. Исправленная версия расположена в корне проекта.

## Запуск модульных тестов

```bash
python -m unittest -v
```

## Анализ покрытия

```bash
python -m coverage run -m unittest
python -m coverage report -m
python -m coverage json -o coverage_results.json
```

## Мутационное тестирование

```bash
python run_mutations.py
```

Результат сохраняется в `mutation_results.json`.
